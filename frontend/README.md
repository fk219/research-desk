# Perplexity: web client

React 19 + Vite + Redux app for the research desk. The root [README](../README.md) covers the product, backend, environment variables and deployment.

```bash
npm install
npm run dev     # http://localhost:5173
npm run build
```

The API origin defaults to the deployed Render service. Set `VITE_API_URL` to point at a local API.
